## ⚡ 5-Minute Quick Start

### Prerequisites
- Python 3.8+
- Anthropic API Key (free account at https://console.anthropic.com)

### Installation
```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Set API key
export ANTHROPIC_API_KEY="sk-ant-xxxxx"

# 3. Run application
streamlit run hr_email_generator.py

# 4. Open browser
# http://localhost:8501
```

### First Email Generation
1. Select scenario: 🎯 Joining Date Clarification
2. Pick an employee from dropdown
3. Add context: "Employee concerned about start date, background check pending"
4. Choose tone: Empathetic
5. Click "Generate Email"
6. Review and copy!

**Total time: 2-3 minutes** ⏱️
